# What is known about this game's 3D models: tables whose layout is understood, one rule per line.
# `tools/model_map.py` reads this file, scans the disc for models and names each one by the first of:
# a rule here, a data symbol, the functions that use its table. Addresses are hex; `_` is a space in labels.
# Rules (the full syntax is in the header of tools/model_map.py):
#   array <addr> <count> <group> <label>            pointers at addr + 4*i: "<label> <i>"
#   chars <addr> <count> <group> <slot:label,...>   a table of pointers to arrays of part pointers
#   structs <addr> <stride> <count> <namestr off> <group> <off:label,...>   records holding model pointers
#   note <group> <first id> <last id> <text>        adds " (<text>)" to the sub-group of those characters
#   rig / bone / assemble                           a skeleton posed from a motion record: whole characters
#   nodes / nodelayout                              node trees in the executable (per character), placed in their bind pose
#   textures <model file> <texture file> <texture base> <table addr>   a texture list: number -> place in the file
#   textures <model file> <texture file> index   texture n = the n-th texture of the PVM archive <texture file> (for a model file that
#                                                keeps its texture lists in its own data). To find the pair: the model file holds the texture names
#                                                (the entry names of a PVM's PVMH header) as text; the archive whose names it holds is its texture file
#   motions <model file> <motion file>          the motions in <motion file> animate the models of <model file> with as many objects as they have
#                                                nodes (a skeleton in the viewer), for files of different names (e.g. a character's motion bank and the
#                                                executable that holds the character)
#   name <file> <offset> <text>   /   table <addr> <group> <label>   /   sound <file> <entry> <text>   /   image <file> <offset> <text>   names (the viewer writes these)
# Nothing is needed here to start: with no rules the map still lists every model, grouped by the table that holds it.
